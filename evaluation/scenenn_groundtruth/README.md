# SceneNN Ground Truth Download

This directory should contain the ground truth data downloaded from the SceneNN dataset. It is recommended to download the data following this repository's instructions: [https://github.com/josematez/SceneNN](https://github.com/josematez/SceneNN).

After downloading some scenes (e.g., 011, 016, ...), the `scenenn_groundtruth` folder should have the following structure:

```
scenenn_groundtruth/
├── 011/
│   ├── 011.ply
│   ├── 011.xml
│   ├── semantic_ground_truth.json
│   └── semantic_ground_truth.png
├── 016/
│   ├── 016.ply
│   ├── 016.xml
│   ├── semantic_ground_truth.json
│   └── semantic_ground_truth.png
...
```
